Not set up yet? Show setup instructions + script
1. Go to sheets.google.com → create a blank spreadsheet.
2. Extensions → Apps Script → delete the default code, paste the script below.
3. Deploy → New deployment → Web app → Execute as Me, Access Anyone → Deploy → authorize it.
4. Copy the Web app URL (ends in /exec).
5. Paste that URL into the SHEET_API_URL constant near the top of this file's <script> tag, replacing the empty quotes. Then re-paste the whole file into your Google Sites embed and republish.
6. This version supports accounts (email + password) — three tabs (Users, Sessions, UserData) are created automatically on the sheet. If you're upgrading from an older single-blob version, redeploy via Deploy → Manage deployments → edit → New version to keep the same URL, then export/import your old backup after creating your account.

Export

Download a backup, or a CSV to open in a spreadsheet.

Import

Restore from a previously downloaded backup file. This replaces current data.

Import sales from CSV

Adds sales without replacing anything. Each row is matched to an existing carrier and product by name (case-insensitive) — if a match is found, that product's saved comp/advance/cap rates are used automatically. Unmatched carriers or products are created for you.

Show accepted column headers

Recognized headers (case-insensitive, order doesn't matter): Date, Effective Date, Client, Carrier, Product, Premium Type (Monthly/Annual), Premium, Comp %, Advance %, Advance Cap, Status, Backend Received (Yes/No), Notes. Only Client, Carrier, and Premium are required — everything else is optional and falls back to carrier/product defaults. This matches the same format the "Download CSV" button above produces, so round-tripping just works.

Storage note

Without cloud sync configured above, this tracker only saves to this specific browser on this device — it will not carry over to your phone or another browser, and some embedded contexts (like Google Sites) may not reliably save at all. Set up Cloud Sync above for true cross-device access, and export a backup occasionally either way.
